# Manual test checklist — 0.42.0-alpha.6

## Page controls

- Confirm **Anamorphic Format** is last in the Page section.
- Confirm **Facing Pages** is in the Page section before **Anamorphic Format**.
- Confirm **Lock Format Ratio** is disabled when Anamorphic Format is off.
- Enable Anamorphic Format and confirm Width and Height become editable.
- Enable Lock Format Ratio and edit Width; confirm Height changes proportionally.
- Enable Lock Format Ratio and edit Height; confirm Width changes proportionally.
- Confirm Grid Group, Columns, Rows, and margin factors are preserved when editing Width/Height.

## Document Options

- Confirm **Use A-Parent** appears instead of Use A-Master.
- Confirm **Emetric Index Page** and **Placeholder Text** are last in Document Options.
- Confirm **Apply Column Gutters** appears in the Column Grid section.

## Preview and pasteboard

- Confirm Preview is checked by default.
- Confirm Preview is placed next to Compact View.
- Confirm version/copyright text is left-aligned in the bottom bar.
- Create a document and confirm InDesign’s Preview Background is set to **Match to Theme Color**.
