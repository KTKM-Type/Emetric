# Roadmap

This roadmap is intentionally lightweight during public beta.

## Planned / under consideration

### More units

- Add Japanese **Q** as a unit option.
- Consider related Japanese typographic units if they fit the Emetric model.
- Verify conversion behavior across mm, pt, picas, ciceros, Didot points, Edo and Q.

### Page orientation

- Add an orientation control in Page Size:
  - Portrait;
  - Landscape.
- Switching orientation should swap Width and Height.
- Page Ratio, guides and preview should update consistently.
- Orientation should work for preset formats and manual Custom Format values.

### Public beta feedback

- Collect testing feedback from designers and typographers.
- Prioritize stability across InDesign versions and operating systems.
- Improve manual test coverage.
- Refine wording, labels and tooltips.

## Future commercial model

Emetric is currently a free public beta under the Emetric Beta License. Future stable releases may require a paid commercial license for professional or organizational use.
