# Beta testing guide

Use `tests/manual-test-checklist.md` as the main structured test document.

## Priority test areas

1. Launch Emetric in different InDesign versions.
2. Switch between Compact View and Full Settings.
3. Test Metric Source changes:
   - Selected Font;
   - Emetric Decimal;
   - Emetric Dozenal;
   - Custom Metric.
4. Test Page Size formats such as A4, A3 and Letter.
5. Test Custom Format page resizing.
6. Test Vertical Grid Alignment, especially Ascender, Cap Height and x-Height.
7. Generate documents with:
   - Grid Guides on/off;
   - Row and Column Gutter Guides on/off;
   - Placeholder Text on/off;
   - Emetric Data on/off.
8. Check generated layers and paragraph styles.
9. Save, reload and delete presets.

## Bug report essentials

Include:

- exact Emetric version;
- InDesign version;
- operating system;
- UI language/locale;
- selected font and style;
- Metric Source;
- page size and grid settings;
- screenshot or screen recording.
