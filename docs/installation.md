# Installation

Copy the versioned `.jsx` file from `dist/alpha/` or the source file from `src/indesign/` into the Adobe InDesign Scripts Panel folder, then run it from the Scripts panel.

For development, use:

```text
src/indesign/Emetric.jsx
```

For manual alpha testing, use:

```text
dist/alpha/Emetric-0.42.0-alpha.6.jsx
```
