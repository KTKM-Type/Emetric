# Security Policy

Emetric is an Adobe InDesign ExtendScript beta.

## Reporting issues

For security-sensitive issues, contact Kristian Möller / KTKM Design AB directly rather than opening a public issue.

For ordinary reproducible bugs, use GitHub Issues.

## Scope

Security reports may include:

- unexpected file access;
- unsafe preset handling;
- script behavior that modifies files unexpectedly;
- issues related to generated documents or local data storage.
